      Experiment 3: The photoelectric effect

      Scientists found that light shining on a metal can knock electrons out of it. The surprise was which light works. Test the colors and brightness, then read what's going on below.

      UltravioletVisibleInfrared
      Electrons knocked out
      Energy in one photon
      Red line = energy needed to free an electron
      Electron speed—

      What's going on?

      If light were only a wave
      • Brighter light carries more energy, so any color should knock out electrons if it's bright enough.
      • Dim light would need time to “build up” energy before electrons come out.
      What actually happens
      • Red light never knocks out electrons, no matter how bright.
      • Violet and UV light knock out electrons right away, even when dim.

      How photons explain it

      1. Light comes in tiny packets called photons. Each photon carries a set amount of energy, called a quantum.
      2. The color decides how much energy each photon has. Shorter wavelength (violet, UV) = more energy. Longer wavelength (red, infrared) = less energy.
      3. One photon hits one electron. If that photon has enough energy, the electron breaks free. If it doesn't, nothing happens. The electron can't save up energy from several weak photons.
      4. Brightness is the number of photons. Brighter light sends more photons, so more electrons come out. It doesn't make each photon stronger.
      5. Extra energy becomes speed. A photon with more energy than needed sends the electron flying off faster.
      Think of it like this: You're trying to knock a can off a fence. Throwing a thousand ping-pong balls (red photons) won't do it, because each one is too weak. One baseball (a violet photon) knocks it right off. Throwing more baseballs knocks off more cans.

      Why it matters: Interference shows light acts like a wave. The photoelectric effect shows light acts like a particle. Light does both. That is wave-particle duality.

        Experiment 4: The observer effect

        Now fire photons or electrons at the two slits one at a time. Each one lands on the screen as a single dot. What pattern do the dots make? And what changes if we put a detector at the slits to see which slit each one goes through?

        Detector at the slits
        Fire
        Dots on screen0
        Pattern: stripes (wave)

        What's going on?

        1. Each one lands as a single dot. That's particle behavior.
        2. With no detector, the dots slowly build up stripes. Stripes come from interference, which only waves do. So each one acts like a wave that goes through both slits and interferes with itself.
        3. With the detector on, we find out which slit it went through. To detect it, we have to interact with it. Now it acts like a particle going through just one slit, and the stripes disappear. You get two bands.

        The observer effect: Measuring something can change how it behaves. Light and electrons act like waves when we don't measure their path, and like particles when we do.
